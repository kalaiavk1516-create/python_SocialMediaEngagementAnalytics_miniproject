# python_SocialMediaEngagementAnalytics_miniproject

📱 Social Media Engagement Analysis
🔹 Project Type
Python Mini Project – Data Cleaning, Wrangling & Visualization

🔹 Overview
This project analyzes a dataset of 5,000 social media posts to understand engagement patterns across users, countries, post types, and sentiments. Using Pandas, NumPy, Seaborn, Matplotlib, and Plotly, the project demonstrates how to clean raw data, wrangle features, and generate insights through visualizations.

🔹 Features
✅ Data Cleaning

Handle missing values in age, gender, likes, comments, shares, and sentiment.

Normalize categorical fields (gender, sentiment).

Remove duplicates and invalid values.

Convert posted_at to proper datetime format.

✅ Data Wrangling

Create new features: engagement_score, log_impression, hashtag_count.

Group and aggregate metrics by post type, category, country, and sentiment.

Statistical analysis: mean, median, mode, variance, quantiles.

✅ Exploratory Data Analysis (EDA)

Correlation matrix and heatmap for numeric fields.

Distribution plots for age, engagement rate, and post types.

Grouped insights:

Average likes by post type.

Engagement rate by country, category, and sentiment.

Age‑wise engagement trends.

✅ Visualizations

📈 Scatterplots (Likes vs Impressions, Distance vs Fare style).

📊 Bar charts (Posts by category, average likes).

🥧 Pie charts (Gender distribution, payment methods).

📉 Histograms (Age distribution, trip distances).

📦 Boxplots & Violin plots (Engagement rate, followers vs sentiment).

🔥 Heatmaps (Correlation between numeric features).

🎨 Interactive Plotly scatterplots for deeper exploration.
